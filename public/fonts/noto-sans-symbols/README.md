# Noto Sans Symbols

From [Google Fonts](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notosanssymbols),
commit `8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`.

`NotoSansSymbols[wght].ttf` was compressed to `NotoSansSymbols.woff2` using
`woff2_compress` 1.0.2 without changing the glyphs. This variable terminal
fallback covers symbols missing from JetBrains Mono and Noto Sans Symbols 2.
