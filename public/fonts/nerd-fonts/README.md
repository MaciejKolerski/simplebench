# Symbols Nerd Font Mono

From [Nerd Fonts v3.5.0](https://github.com/ryanoasis/nerd-fonts/tree/v3.5.0/patched-fonts/NerdFontsSymbolsOnly).

`SymbolsNerdFontMono-Regular.ttf` was compressed to WOFF2 using
`woff2_compress` 1.0.2 without changing the glyphs. This terminal fallback
provides Nerd Font icons without changing the primary text font.
Redistribution terms are included in [LICENSE](LICENSE); upstream documents
the [included icon sets, authors, and licenses](https://github.com/ryanoasis/nerd-fonts/blob/v3.5.0/patched-fonts/NerdFontsSymbolsOnly/README.md#icon-sets).
