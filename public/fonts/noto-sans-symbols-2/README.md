# Noto Sans Symbols 2

From [Google Fonts](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notosanssymbols2),
commit `8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`.

`NotoSansSymbols2-Regular.ttf` was compressed to WOFF2 using
`woff2_compress` 1.0.2 without changing the glyphs. This terminal fallback
covers Braille patterns and Unicode symbols missing from JetBrains Mono.
